<Info>
This documentation reflects the current **MVP** version of the Flumes Memory API with path prefix `/v0`. Core endpoints include `/v0/context/assemble`, `/v0/memories`, `/v0/recall`, `/v0/summarize`, `/v0/prune`, and `/v0/observability/events`. Internal endpoints (not for SDKs) include `/v0/extract` and `/v0/memories:batch_upsert`.
</Info>

## Base URL

```text
https://api.flumes.ai/v0
```

<Tip>
This endpoint is served from Flumes Cloud at `https://api.flumes.ai`. If you run the API locally the base URL is typically `http://localhost:8000`.
</Tip>

## Authentication

All requests must include an API key using the `Authorization` header. Optionally set `X-Flumes-Agent` to scope traffic to a specific agent within your org. You may also provide `Idempotency-Key` for safe retries.

<ParamField header="Authorization" type="string" required>
Bearer token for authentication. Format: `Authorization: Bearer <YOUR_API_KEY>`.
</ParamField>

<ParamField header="X-Flumes-Agent" type="string">
Optional agent id within your org.
</ParamField>

<ParamField header="Idempotency-Key" type="string">
Optional. Unique per org; ensures safe retries for write requests.
</ParamField>

<Info>
You can generate and manage your API keys from the Flumes dashboard at [app.flumes.ai](https://app.flumes.ai/).
</Info>

If the key is missing or invalid the server responds with **401 Unauthorized**.

## Rate limits

<Warning>
Rate limits are enforced per API key. When rate limited, responses include `X-RateLimit-Remaining` and `X-RateLimit-Reset` headers and return **429 Too Many Requests**.
</Warning>

## Error handling

All error responses share a common JSON structure:

```json
{
  "error": "validation_error",
  "message": "Field 'type' must be one of [fact,event,document,note,profile,chunk]",
  "request_id": "req_123",
  "details": {
    "field": "type"
  }
}
```

The following table lists standard HTTP status codes returned by the API:

| Code | Meaning | Typical causes |
|------|---------|----------------|
| 400  | Bad Request | Missing required parameters, invalid JSON payload |
| 401  | Unauthorized | API key missing / revoked |
| 404  | Not Found | Resource does not exist |
| 429  | Too Many Requests | Rate limit or monthly quota exceeded |
| 500  | Internal Server Error | Unhandled exception on the server |
